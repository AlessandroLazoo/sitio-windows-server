Información Básica

Conceptos fundamentales de la arquitectura implementada en Windows Server.

Active Directory (AD DS)

Servicio de directorio que centraliza la gestión de identidades, Unidades Organizativas (UO) y permisos de acceso remoto mediante protocolos seguros de autenticación en red.

Internet Information Services (IIS)

Servidor web nativo de Windows Server encargado de alojar y servir aplicaciones y sitios estáticos o dinámicos desde el directorio raíz C:\inetpub\wwwroot\.

Escritorio Remoto (RDP) y Git

El protocolo RDP (puerto 3389) habilita la administración gráfica remota, mientras que Git permite clonar repositorios directamente en la ruta de producción del servidor.

Problemas y Soluciones

Haz clic sobre cada incidencia frecuente para desplegar su diagnóstico y solución técnica.

1. Error 404 (Not Found) al abrir el sitio en localhost
Problema: Al clonar el repositorio con git clone URL sin especificar destino, Git crea una subcarpeta adicional con el nombre del repositorio, dejando el index.html fuera de la ruta esperada por IIS.
Solución: Navegar hasta la carpeta personal con cd y ejecutar git clone URL_REPOSITORIO . (incluyendo el punto final) para descargar los archivos directamente en el directorio actual.
2. Fallo de autenticación al conectar por Escritorio Remoto (RDP)
Problema: El cliente RDP intenta iniciar sesión usando el dominio local de la computadora física en lugar del dominio configurado en el servidor Active Directory.
Solución: Seleccionar "Más opciones" > "Usar otra cuenta" e ingresar las credenciales anteponiendo el nombre del dominio o utilizando el formato usuario@dominio.local asignado por el líder.
3. Denegación de permisos en la carpeta del servidor web
Problema: El usuario intenta crear carpetas o clonar archivos fuera de la Unidad Organizativa o directorio asignado a su grupo de trabajo.
Solución: Verificar mediante cd que la ruta de trabajo corresponda exactamente a la carpeta delegada al grupo en C:\inetpub\wwwroot\, respetando las políticas de seguridad.
